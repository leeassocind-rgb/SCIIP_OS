# SCIIP_OS v5.6 Wave 2.7 — Semantic Evidence Resolution

This sprint replaces single-namespace evidence matching with governed multi-strategy resolution:

- exact evidence ID
- normalized evidence URI/URN
- source-file match
- property, event, and transaction context
- confidence-weighted text similarity
- human review queue for unresolved or low-confidence matches

It rebuilds the provenance graph and executive evidence KPIs and also audits suspicious canonical identity collapse groups.
