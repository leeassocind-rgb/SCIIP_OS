# SCIIP_OS v8.2.1 Self-Configuring Canonical SuperSheet Resolution

This maintenance release makes canonical SuperSheet resolution self-configuring.

- Automatically discovers the existing v8.1 profile in the repository.
- Accepts an optional profile JSON, ZIP, SuperSheet ZIP, or directory.
- Generates the profile through the installed v8.1 native parser when necessary.
- Searches common Downloads/Desktop locations as a final fallback.
- Preserves governed, evidence-backed processing with production writes disabled.
