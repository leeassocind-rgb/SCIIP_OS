This package repairs only the failed diagnostic instrumentation strategy from R4-R3-R3.

The prior package inserted breadcrumbs into a multiline object literal and failed Node syntax checking. The authoritative R29B runner was restored before exit.

R4-R3-R3-R1 instruments only syntax-safe statement boundaries in the post-preflight synchronous region, validates the instrumented runner with node --check before execution, runs under an 8-second bound, and restores the runner byte-for-byte.

No governed data mutation.
No property click.
No Assignments invocation.
No Generate invocation.
No Export invocation.
